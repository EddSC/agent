# Agente USB POS — Releases

Repositorio **público** que aloja únicamente los **releases** del agente de
impresión USB para el POS de Odoo (`pos_usb_printer`).

- Código fuente: repo privado `EddSC/Nexora`.
- Releases: `https://github.com/EddSC/agent/releases`
- Canal de actualización del agente:
  - Manifest: `https://github.com/EddSC/agent/releases/latest/download/manifest.json`
  - Binario: `https://github.com/EddSC/agent/releases/latest/download/pos_usb_agent.exe`

Los releases se publican automáticamente con GitHub Actions al subir un tag
`vX.Y.Z` en el repo fuente.
